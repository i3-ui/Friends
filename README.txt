THE FRIENDSHIP TIME MACHINE — STARTER WEBSITE

Preview: open index.html in a browser.

ADD YOUR MUSIC:
1. Put your audio file in assets/music/
2. Rename it to your-music-file.mp3
   OR change the audio src in index.html to your exact filename.
3. Audio begins after the visitor presses PLAY MUSIC & ENTER.

UPLOAD:
Upload index.html and the entire assets folder to GitHub Pages.
This first build is universal and contains no fixed personal names.
